# contracts/

The single source of truth for every wire format in Aex. Everything else is generated from here
by `tools/gen.sh` and checked for drift in CI.

| Path | What | Consumers |
| --- | --- | --- |
| `abi/v1/abi.json` | brain ↔ hand ABI v1 (JSON Schema 2020-12); semantics in `abi/v1/README.md` | `brain`, `hands` (Rust, via `crates/aex-contracts`) |
| `abi/v1/tools/manifest.json` + `.digest` | the sealed tool set of the curated hand image (v1) and its pinned digest | brain seals it at create; hand serves it |
| `session/v1/schemas.json` | public session API component types | control plane, brain, SDK/CLI |
| `session/v1/openapi.yaml` | public session API paths (references `schemas.json`) | SDK/CLI (`packages/contracts` `paths.ts`), docs |
| `control/v1/schemas.json` | control plane component types: identity, prepaid billing, rated usage | control plane, SDK/CLI |
| `control/v1/openapi.yaml` | control plane paths (identity + billing; session paths are served verbatim from `session/v1`) | SDK/CLI (`control-paths.ts`), docs |
| `examples/**` | one worked example per message type, `<TypeName>.<case>.json` — the conformance corpus; regenerated by `tools/make-examples.py` | tests in both languages |

Rules:

* Change the schema first, run `tools/gen.sh`, commit schema + generated code together.
* Within a major version, changes are additive (new optional fields, new enum values are **not**
  additive for consumers that exhaustively match — bump minor and note it). Removing or re-typing a
  field is a new major.
* ABI: unknown fields are ignored (no `additionalProperties: false`). Session API: request bodies
  are strict (typos fail fast); responses and events are open.
* Optional fields are absent when unset, not `null`. Required nullable fields use `null`.
* Absent provider counters are absent — never reported as 0.
