# contracts/

The source of truth for Aex-owned onboarding, identity, prepaid model billing, and account-policy
formats. Neutral session, Agentloop, model, Tool, and Environment protocols live in
[`aexhq/brain`](https://github.com/aexhq/brain).

| Path | What | Consumers |
| --- | --- | --- |
| `control/v1/schemas.json` | hosted account, API-key, prepaid balance, model-usage, and rate-policy types | control plane, SDK/CLI |
| `control/v1/openapi.yaml` | Aex-owned hosted control paths | SDK/CLI (`control-paths.ts`), docs |
| `examples/control/**` | one worked example per Aex message type, regenerated by `tools/make-examples.py` | tests in both languages |

Rules:

- Change the schema first, run `tools/gen.sh`, and commit schema and generated code together.
- This is a pre-launch contract and is modified in place; do not add compatibility layers.
- Optional fields are absent when unset, not `null`. Required nullable fields use `null`.
