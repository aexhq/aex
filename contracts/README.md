# contracts/

The source of truth for Aex-only account, billing, and control-plane wire formats. Neutral session
and Brain↔Hand protocols live in [`aexhq/brain`](https://github.com/aexhq/brain).

| Path | What | Consumers |
| --- | --- | --- |
| `control/v1/schemas.json` | control plane component types: identity, prepaid billing, rated usage | control plane, SDK/CLI |
| `control/v1/openapi.yaml` | Aex identity and billing paths | SDK/CLI (`control-paths.ts`), docs |
| `examples/control/**` | one worked example per Aex message type, regenerated by `tools/make-examples.py` | tests in both languages |

Rules:

* Change the schema first, run `tools/gen.sh`, commit schema + generated code together.
* Within a major version, changes are additive. Removing or re-typing a field is a new major.
* Optional fields are absent when unset, not `null`. Required nullable fields use `null`.
* Absent provider counters are absent — never reported as 0.
