# AEX

AEX runs agents in durable sessions. Each session keeps its messages and one
isolated MicroVM, so work can pause and resume in the same workspace.

You bring the model and provider credential. AEX pins both to the session and
keeps the credential outside the MicroVM. Usage and telemetry remain available
when the MicroVM is suspended or terminated.

The code is open source. AEX is still in prelaunch development, so expect
breaking changes and interruptions. Do not use it for production work yet.
