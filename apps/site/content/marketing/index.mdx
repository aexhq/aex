AEX is a distributed agent runtime in the cloud for developers to build and run
agent sessions for their apps. Each session has a model, an isolated Linux
workspace, files, and tools. Control it through the TypeScript SDK or HTTP API.

- [Read the docs](/docs)
- [Log in](https://aex.dev/signin?next=/app)

## 800+ models

Use 800+ models across OpenAI, Anthropic, Google, DeepSeek, Z.ai, Moonshot AI,
OpenRouter, and Vercel AI Gateway. Bring your own provider key and choose the
model for each session.

## Sessions

Run multi-message sessions for up to eight hours. Idle sessions suspend after
three minutes and resume with the same workspace on the next message. Start,
inspect, suspend, resume, or stop sessions through the API.

## Files, skills, and tools

Upload project files, `AGENTS.md`, custom instructions, skills, tool bundles,
MCP configuration, and other assets. Mount the files each session needs.

## Built-in tools

Every session includes Bash, `read_file`, `edit_file`, and `write_file`.
Preinstall pinned apt, pip, and npm packages, then allow or block public network
access.

## Compute and subagents

Choose from 512 MB, 1 GB, 2 GB, 4 GB, or 8 GB of memory. Agents can create
recursive subagents in the same session and workspace.

## Observability

Stream messages as AG-UI events. Query, stream, or export OpenTelemetry logs,
spans, metrics, and traces, including after a session suspends or stops.

## Pricing

AEX runtime usage is free during alpha. Model usage is billed by the provider
through your own key.

> AEX is currently in alpha. Expect breaking changes and occasional interruptions.
