AEX is a distributed agent runtime in the cloud. Developers use it to run and
manage agent sessions for their apps.

- [Read the docs](/docs)
- [Log in](https://aex.dev/signin?next=/app)

## Sessions

Start a session, continue it later, inspect its state, or stop it through one
API.

## Workspaces

Each session runs in an isolated cloud workspace with shell and file tools.

## Models

Use the model provider and credentials you already have.

## Observability

Follow messages and telemetry while the agent works. AEX records usage too.

> AEX is open source and still in prelaunch. Do not use it in production yet.
