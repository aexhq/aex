Aex gives your agent a session. It remembers the whole conversation, works on
its own Linux machine, reads the files you hand it, and uses tools that touch
real things. You bring the model key. Aex runs the rest.

- [Read the docs](/docs)
- [Log in](https://aex.dev/signin?next=/app)

## Your key, your model

Pick a model from OpenAI, Anthropic, DeepSeek, xAI, Meta, Moonshot AI, or
Alibaba, and give the session your own provider key. It is encrypted the moment
it arrives, never handed back, and never shared with another session.

## A session that remembers

One session holds the whole conversation. Stop the current work, shut the
machine down and keep the transcript, or delete everything for good. There is
nothing else to keep track of.

## A machine of its own

Every session gets its own Linux machine. It starts warming up as soon as the
session is created, sleeps when nothing is running, and wakes up where it left
off. Sessions that need no machine can say so and get none.

## Files it can read

Give the session images, PDFs, video, source trees, or notes, as text, a link,
or a direct upload. They show up at fixed paths on the machine, and a later
upload cannot change a session that is already running.

## Tools that do real work

The model can run shell commands, read and write files, and call your own MCP
servers. Big results stay on the machine until the model decides one is worth
keeping.

## Helpers when it needs them

The model can start child agents and run independent work at the same time.
Results come back in the order they were asked for, so the transcript still
reads straight through.

## Watch it work

Follow the answer as it is written, along with tool activity, logs, and usage.
Watching never slows the model down, and everything is kept so you can replay
or download it later.

## Pay for what you run

Top up a balance and see where it went by session, model, or kind of work.
Cards are handled on hosted pages, and your model tokens are billed by your
provider rather than by us.

## Not here yet

There are no hosted web search or browser tools, no shared store for secrets
or skills, and no way to send your telemetry somewhere else. Those are on the
list, and this page will say so when they arrive.

> Aex is in active prelaunch development. Expect breaking changes and occasional interruptions.
