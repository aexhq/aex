title: AEX
description: AEX is a session-centered agent runtime with files, tools, MCP, subagents, telemetry, and prepaid controls.
---

AEX gives your app one durable execution unit: a session. It owns committed
message history, an exact model, a file-aware Linux workspace, tools, subagents,
and telemetry. Control it through the TypeScript SDK or HTTP API.

- [Read the docs](/docs)
- [Log in](https://aex.dev/signin?next=/app)

## Official models

Bring one session-scoped provider key and choose a qualified model from OpenAI,
Anthropic, DeepSeek, xAI, Meta, Moonshot AI, or Alibaba. The key is encrypted,
never returned, and never reused by another session.

## Durable sessions

Keep a multi-message conversation for up to eight hours. Cancel current work,
terminate compute while retaining committed messages, or irreversibly delete
session content. There is no separate public run resource to coordinate.

## Latest-only files

Messages are text-only. Register arbitrary latest-only files from inline bytes,
an HTTPS URL, or a direct upload, freeze their sandbox paths at session creation,
then point the model to images, PDFs, video, source trees, or instructions there.

## One sandbox

The default sandbox starts preparing in the background at session creation and
suspends when no tool is waiting. The first sandbox call waits for the exact
generation to resume. Disable it explicitly to allocate no sandbox and return a
structured error for sandbox-only tools.

## Tools and MCP

Use Bash, `read_file`, `edit_file`, `write_file`, and `mcp_call`. Configure
remote HTTP or sandbox-process MCP per session. Large results stay in sandbox
files until the model calls `storage.persist` to publish one as a workspace file.

## Parallel subagents

Independent tool calls can run together while their results commit in model
call order. Native subagents have their own durable identities, with at most 12
child identities over a session lifetime and maximum depth 3.

## Live and retained telemetry

Stream bounded assistant previews, tool activity, runtime events, logs, spans,
and usage without delaying model work. Gaps are explicit, every assistant answer
gets committed reconciliation, and retained telemetry supports replay and
compressed download.

## Prepaid billing

Use hosted card and top-up flows, inspect balance and immutable transactions,
and filter usage by session, provider, model, or category. Model spend remains
with the provider behind your own key; AEX never stores raw card details.

> AEX is in active prelaunch development. Expect breaking changes and occasional interruptions.
